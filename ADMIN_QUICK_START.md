- **Login Page**: `https://digitalnyn2062.builtwithrocket.new/admin/login`

## 📋 Step-by-Step: First Time Setup

### 1. Create Admin User in Supabase

1. Open your Supabase project dashboard
2. Go to **Authentication** → **Users**
3. Click **"Create new user"**
4. Fill in:
   - **Email**: `admin@digitalnyne.com` (or your email)
   - **Password**: Create a strong password
5. Click **"Create user"**

### 2. Login to Admin Dashboard

1. Go to: `https://digitalnyn2062.builtwithrocket.new/admin/login`
2. Enter your email and password
3. Click **"Sign In"**
4. You'll see the admin dashboard

### 3. Explore the Dashboard

- **Top Right**: Your email address
- **Stats Cards**: Dashboard metrics (expandable)
- **Quick Actions**: Common tasks
- **Logout Button**: Sign out when done

## 🆘 Troubleshooting

### "Cannot login"
- Check email and password are correct
- Verify user exists in Supabase
- Try resetting password in Supabase

### "Redirects to login page"
- Session may have expired
- Try logging in again
- Clear browser cookies and try again

### "Page not loading"
- Check internet connection
- Try refreshing the page
- Check browser console for errors
